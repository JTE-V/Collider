```json
{
  "claim": "<本次主张>",
  "origin": {
    "精确表述": "",
    "条件": "",
    "量词": "",
    "常数": ""
  },
  "collision_point": {
    "特例": "",
    "期望数值": null,
    "独立来源": ""
  },
  "falsification": {
    "作废条件": ""
  },
  "status": "[已自推] | [仅引用，未撞]",
  "self_derivation": "",
  "collision_result": {
    "computed": null,
    "reference": null,
    "delta": null
  },
  "honesty": {
    "speculation_marked": true,
    "facts_count": 0,
    "speculations_count": 0
  }
}
```

纪律：只输出材料与对撞记录，**不下"这题解决了"类结论**。
