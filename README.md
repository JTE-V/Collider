## 00 定位

### 它不是什么

| 它不是 | 说明 |
|---|---|
| **不是 agent** | 无自主行动、不调工具链、不替使用者下判断、不产生"我认为"。判定权始终在使用者。 |
| **不是 prompt** | 不是一次性注入词，不靠措辞生效，不随模型重写而失效，换宿主零改动。 |

### 它是什么

一套**判据纪律层**，只约束一件事：**什么算一次合格的交付**。

### 它治什么病

- 未经对撞就采信前人结论
- 把"自洽"当成"正确"

## 01 红线

定义什么算"未交付"。**违反任何一条 = 本次输出判 FAIL，无论其他部分多好。**

### P1 不采信未对撞的前人结论

任何前人结论进入本次输出，一律只算**待对撞物**，不算依据。

### P2 自洽不作为判据

"逻辑通顺／闭环／严格对应"不构成通过理由。判据只有对撞结果。

### P3 四项不齐不受理

原命题精确表述／可撞点／证伪条件／状态标签，缺一视为未交付，不进评审。

### P4 不得擅自升级状态标签

`[仅引用，未撞]` 不得写成 `[已自推]`。

### P5 不得伪造对撞

声称"精确匹配／严格对应"却未给出**实际算出的数值** = 伪造对撞 = FAIL。

## 02 判卷标准

每条标准独立成立，**任一条不满足即 FAIL**。

### 2.1 四项齐备

原命题精确表述、可撞点、证伪条件、状态标签四者同时存在。缺一 FAIL（注明缺哪个）。

### 2.2 原命题精确表述

必须含三要素：**条件**（定义域／前提／边界）、**量词**（∀／∃／n>1 类）、**常数**（含有效位）。三要素缺一 → 不合格 → FAIL。

### 2.3 可撞点

必须是能产生**同一具体数值**的特例，且该数值可与**独立来源**对照。只有形式描述、落不到数值 → FAIL。

### 2.4 证伪条件

必须**事先**给出：什么情况下本条作废。事后追加或不可检验 → FAIL。

### 2.5 状态标签

必须显式标 `[已自推]` 或 `[仅引用，未撞]`。未标／双标／含糊 → FAIL。

### 2.6 自推优先

`[已自推]` 必须附**自行推导过程**，且推导在对撞**之前**。先引用后补推 → FAIL。

### 2.7 数值存在性

出现"匹配／对应／一致"等判断词，必须附**实际算出的数值 + 对照来源**。有判断词无数 → FAIL。

### 2.8 交叉验证

见[运行规程 A](#运行规程-a通信网)。

### 2.9 偏差归零

见[运行规程 B](#运行规程-b逆向导构消元)。

## 03 错题本

FAIL 时按 P-code 归因。**一次修正只改一处，重跑验证，PASS 后沉淀。**

| 代码 | 症状 | 根因 | 修正动作 | 验证手段 |
|---|---|---|---|---|
| P01 | 直接套用前人结论 | 未走对撞 | 降级为待对撞物，先自推 | 2.6 |
| P02 | 只有自洽论证，无数 | 把自洽当正确 | 补可撞点数值 | 2.7 |
| P03 | 四项缺项 | 交付不完整 | 补齐缺失项 | 2.1 |
| P04 | 命题表述模糊 | 缺条件／量词／常数 | 精确化三要素 | 2.2 |
| P05 | 可撞点产不出数值 | 空壳特例 | 换成可算的具体特例 | 2.3 |
| P06 | 证伪条件缺失或事后加 | 不可证伪 | 事先写定 | 2.4 |
| P07 | 标签错标／擅自升级 | 状态造假 | 按实际状态改标 | 2.5 |
| P08 | 对撞不一致仍采信 | 护短 | 不一致即判未撞 | 2.3 |
| P09 | 单路径自洽 | 未交叉 | 走规程 A | 2.8 |
| P10 | 偏差未归零就收尾 | 未消元 | 走规程 B | 2.9 |

## 运行规程 A：通信网

**用途：防单路径自洽。** 单条路径自洽不算数。

1. 每条主张至少 **2 条相互独立的路径**各自得出
2. 路径间**交换输出、交叉验证**：路径 A 的输出作为路径 B 的输入约束
3. 存在**不可违反的铁律**约束全部路径结论
4. 判定：
   - 全部对得上 → 可进入对撞
   - **任何一条对不上 → 挂起待查，不得跳过**

## 运行规程 B：逆向导构消元

**用途：对撞出现偏差时的标准流程。** 出现差值，不许改结论、不许放弃，必须走完三步。

1. **找偏差**
   `N(自推) − N(对照) = 差值`
2. **定位漏区**
   分块比对，每段 `[T, T+H]` 各自比对；差值集中在哪段，问题就在哪段
3. **消元**
   对偏差段**细化步长重扫**，补回漏项，再比对；**差值归零**才算消元完成

> 未归零 → 状态一律记 `[未撞]`，不得升为 `[已自推]`。

## 搭载协议

1. **注入**：01 + 02 + 05 作纪律层，06 作示范，03 作归因手册，04 作记忆日志
2. **判卷**：每次输出按 02 判卷（可人工，可脚本执行）
3. **归因修正**：FAIL → 按 03 定位 P-code → 修正 → 再判卷
4. **沉淀**：PASS → 记入 04，成为新的锚
